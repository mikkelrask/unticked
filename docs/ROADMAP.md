# Roadmap

unticked is an early Android development build. The current package and signing key are development identities.

## Available

- Plain todo.txt selection, search and Today/All/Done views.
- Complete/reopen, task editing, additions and conservative session undo.
- Priority, due-date and explicit reminder pickers.
- Existing project/context suggestions.
- Durable private drafts and verified-write recovery copies.
- Opt-in approximate notifications with background reconciliation and delivery-time task checks.
- Vesper, Dark and Light themes.
- Bracket controls, compact task spacing and large-text/short-screen layouts.

## Next

- Handset notification delivery under battery restrictions.
- Manual TalkBack, keyboard navigation and wider device testing.
- Reboot, unavailable-file and interrupted-write validation.
- Local snooze and notification completion actions.
- Decide whether to offer exact-alarm access.
- Choose a project licence, production package, signing and distribution.

Daily due-task digests, widgets and optional portable task IDs remain design possibilities.

The [developer guide](DEVELOPMENT.md) links to test evidence and storage findings. The [generated project brief](design/PROJECT_BRIEF.md) is historical design input, not a description of the current release.
